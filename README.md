## ✨ About the App

**Conet** is a modern social and collaboration platform built to connect people based on skills, interests, and meaningful conversations.

It combines:

* 💬 Real-time chat
* 🤝 Skill-based matching
* 🧠 Knowledge sharing
* 🎨 Beautiful UI with dark/light mode

Designed with **scalability and clean architecture in mind**.

---

## 📱 Features

### 🔐 Authentication

* Email login & signup
* Clean onboarding flow

### 💬 Real-Time Chat

* Smooth chat UI
* Message bubbles with modern design
* Dark & Light mode support

### 🤝 Match System

* Swipe-based matching (like Tinder)
* Like ❤️ / Reject ❌ / Star ⭐ actions
* Skill-based discovery

### 👥 Friends System

* Active users list
* Quick conversation access
* Online indicators

### 📝 Post Feed

* Create and view posts
* Like interactions
* Clean card-based UI

### 👤 Profile

* Avatar customization
* Bio & interests
* Editable user profile

### 🌙 Theme System

* Full dark/light mode
* Seamless UI adaptation

## 🧠 Architecture

```bash
Feature-Based MVVM + Riverpod
```

### 📦 Structure Overview

```
lib/
├── features/
│   ├── authentication/
│   ├── chat/
│   ├── friends_match/
│   ├── home/
│   ├── match/
│   ├── post/
│   ├── profile/
│
│   # Each feature contains:
│   ├── data/
│   ├── model/
│   ├── view/
│   └── view_model/
│
├── common/
├── navigation/
├── util/
│   ├── constants/
│   ├── helpers/
│   ├── theme/
│   └── validators/
│
├── main.dart
└── app.dart
```
